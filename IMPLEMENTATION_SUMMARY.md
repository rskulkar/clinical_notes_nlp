## Implementation Details

### Data Preparation (01_data_preparation.ipynb)

**Input**: `../data/oncology_trial_screening_v02.csv`
- 1,000 unique patients
- 3,028 total notes
- Columns: patient_id, note_date, cancer_indication, free_text_note, eligible, available, deceased, lost_to_follow_up

**Processing**:
1. Load CSV with pandas
2. Convert note_date to datetime
3. Sort by patient_id and note_date
4. Filter to most recent note per patient (1,000 rows)
5. Create STATUS label with priority rules:
   - deceased=1 → DECEASED
   - lost_to_follow_up=1 → CENSORED
   - available=1 & eligible=1 → AVAILABLE
   - available=0 & eligible=1 → ELIGIBLE
   - else → INELIGIBLE
6. Create stratified train/val/test split (700/150/150 samples)

**Class Distribution**:
- INELIGIBLE: 305 (30.5%)
- CENSORED: 145 (14.5%)
- ELIGIBLE: 144 (14.4%)
- AVAILABLE: 129 (12.9%)
- DECEASED: 95 (9.5%)

**Output Datasets**:
- `processed_data.csv`: Full dataset with STATUS and split labels
- `train_data.csv`: 700 samples
- `validation_data.csv`: 150 samples
- `test_data.csv`: 150 samples
- `class_mapping.json`: Status → index mapping

### Approach #1: TF-IDF + Logistic Regression (02_tfidf_logistic_regression.ipynb)

**Text Preprocessing**:
```
Original: "ECOG PS 0. WBC 5.0, Hgb 11.5 g/dL. Creatinine 1.32 mg/dL."
→ Lowercase
→ Remove numbers: "ECOG PS . WBC , Hgb g/dL. Creatinine mg/dL."
→ Remove special chars: "ECOG PS WBC Hgb g dL Creatinine mg dL"
→ Tokenize: ["ECOG", "PS", "WBC", ...]
→ Remove stopwords: ["ecog", "ps", "wbc", ...]
```

**TF-IDF Vectorization**:
- max_features: 5,000
- min_df: 2 (ignore terms in <2 docs)
- max_df: 0.95 (ignore terms in >95% of docs)
- ngram_range: (1, 2) (unigrams + bigrams)
- sublinear_tf: True
- Result: 700×5000 sparse matrix

**Model**:
- Logistic Regression
- max_iter: 1000
- solver: lbfgs
- multi_class: multinomial

**Evaluation**:
- Train, validation, and test metrics
- Weighted F1 (primary)
- Macro F1 (secondary)
- Accuracy
- Per-class precision/recall/F1
- Confusion matrices (3 separate)
- ROC-AUC curves (one-vs-rest for each class + AVAILABLE vs others)
- Feature importance (top 15 per class)

**Artifacts**:
- `tfidf_model.pkl`: Trained model
- `tfidf_vectorizer.pkl`: TF-IDF vectorizer
- `tfidf_metrics.json`: Performance metrics
- `tfidf_confusion_matrices.png`: Train/Val/Test CM
- `tfidf_roc_curves.png`: ROC curves
- `tfidf_feature_importance.png`: Top features per class
- `tfidf_performance_summary.png`: Metric comparison

### Approach #2: Fine-tuned BERT (03_bert_finetuning.ipynb)

**Tokenization**:
- Model: `bert-base-uncased` (12 layers, 768 hidden units, 110M parameters)
- Tokenizer: BertTokenizer
- max_length: 512
- padding: max_length
- truncation: True
- Result: 700×512 token IDs (train), attention masks, token type IDs

**Model Architecture**:
```
Input → BERT Encoder (12 layers) → [CLS] token embeddings → Classification Head → Softmax
                                     ↓
                                  768-dim
                                     ↓
                                  5 classes (LINEAR)
                                     ↓
                                  AVAILABLE, ELIGIBLE, etc.
```

**Training Configuration**:
- Optimizer: AdamW (lr=2e-5, eps=1e-8)
- Scheduler: Linear warmup (10% of total steps)
- Batch size: 16
- Epochs: 5 (with early stopping, patience=2)
- Loss: CrossEntropyLoss
- Device: GPU if available, else CPU

**Early Stopping**:
- Monitor: Validation weighted F1
- Patience: 2 epochs
- Best model saved to `best_bert_model.pt`

**Evaluation**:
- Same metrics as TF-IDF
- Additional: Training loss curves, validation loss curves

**Artifacts**:
- `best_bert_model.pt`: Best model checkpoint
- `bert_model_finetuned/`: Full model directory (model, tokenizer, config)
- `bert_metrics.json`: Performance metrics
- `bert_confusion_matrices.png`: Train/Val/Test CM
- `bert_roc_curves.png`: ROC curves
- `bert_performance_summary.png`: Metric comparison
- `bert_training_curves.png`: Loss and F1 curves
